# **Ejercicio de refuerzo Dart**
Crea la carpeta ejercicios_dart con estos 4 archivos, cada uno con su main():
* **precios.dart**: convierte una lista de precios del cacao de USD por quintal a USD por kilogramo (1 quintal = 45,36 kg).
* **tabla.dart**: con un for anidado, muestra la tabla de multiplicar de las cajas por 1 a 5 lotes.
* **par_impar.dart**: función flecha que indique si un número de parcela es par o impar.
* **clima.dart:** con String? estado nulo, muestra un mensaje por defecto usando ??; luego usa switch para "soleado", "nublado" o "lluvia".
